# Music Player Website using React.js

This is a Music Player website built using React.js, which allows users to play, pause, skip, and control the volume of audio tracks. The website is simple, clean, and responsive, providing a smooth user experience for music lovers.

## Live Demo: https://music-player-spotify1.netlify.app/

## Features
▫ Audio Controls: Play, pause, skip to the next/previous track, and adjust the volume.

▫ Playlist: Users can view and navigate through a list of songs.

▫ Track Progress: See the current progress of the song and skip to a specific point in the track.

▫ Responsive Design: The website is fully responsive and works perfectly across devices (mobile, tablet, desktop).

▫ Smooth Animations: Animated transitions for the play/pause buttons and track progress.

▫ React Context: For managing the global state of the music player (current track, playing status, etc.).

## Technologies Used
▫ React.js: JavaScript library for building user interfaces.

▫ React Hooks: For managing state and lifecycle events (useState, useEffect).

▫ Tailwind CSS: A utility-first CSS framework for fast and customizable styling.

▫ React Icons: For adding icons like play, pause, skip, etc.

▫ Audio API: Used for controlling the audio playback.
